# SHAE Mojo Matrix Calculator

A matrix/tensor calculator written in Mojo.

## Features
- Matrix creation and element access
- Matrix addition
- Matrix multiplication
- Matrix transpose
- Mojo systems programming language

## Install
```bash
./scripts/install.sh
# Or manually:
mojo build src/matrix_calculator.mojo -o shae-matrix-calc
```

## Usage
```bash
mojo src/matrix_calculator.mojo
```

## Design
Follows SHAE Field Manual: warm paper #F2EEE5, ink #191712, oxide #B3341B, 0px radius, 1px borders.
