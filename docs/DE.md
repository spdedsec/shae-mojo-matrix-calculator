# SHAE — Deutsche Dokumentation

## Installation
Führe `scripts/install.sh` aus, um den Mojo-Matrixrechner zu installieren.

## Plattform
CLI-Tool (Mojo-Sprache).

## Build
`mojo build src/matrix_calculator.mojo -o shae-matrix-calc`

## Release
GitHub Release v0.1.0 verfügbar.

## Design
Folgt dem SHAE Field Manual: warm paper #F2EEE5, ink #191712, oxide #B3341B, 0px Radius, 1px Rahmen.
