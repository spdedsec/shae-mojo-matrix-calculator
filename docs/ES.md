# SHAE — Documentación en Español

## Instalación
Ejecute `scripts/install.sh` para instalar la calculadora de matrices en Mojo.

## Plataforma
Herramienta de línea de comandos (CLI) en lenguaje Mojo.

## Build
`mojo build src/matrix_calculator.mojo -o shae-matrix-calc`

## Release
GitHub Release v0.1.0 disponible.
